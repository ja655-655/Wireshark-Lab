Wireshark Lab 

## Objective

Analyze packet captures from a web server under attack to identify the root cause of service disruption, evaluate business impact, and define firewall and IDS defense controls.

### Skills Learned

- Packet Capture Analysis: Interpreting TCP three-way handshake anomalies (`[SYN]`, `[SYN, ACK]`, `[ACK]`).
- Incident Response & Triage: Assessing attack lifecycles and business impact under the NIST Cybersecurity Framework (CSF).
- Network Hardening: Formulating defense-in-depth strategies including SYN cookies, rate limiting, and anti-spoofing firewall rules.

### Tools Used

- Wireshark: Evaluated network traffic captures (`.pcap` / color-coded logs)
